# Kişisel Tanıtım Sayfası

Full-stack developer olma yolunda öğrendiklerimi pekiştirmek için yaptığım, Tailwind CSS ile geliştirilmiş responsive bir kişisel tanıtım sayfası.

## Canlı Demo
https://ssb-dvlpr.github.io/tailwind-tanitim-sayfam/

## Kullanılan Teknolojiler
- HTML5
- Tailwind CSS (Vite ile kurulum)
- Responsive tasarım (mobile-first, `md:` breakpoint kullanımı)

## Özellikler
- Sidebar navigasyon (Hakkımda / Projeler / İletişim)
- Responsive layout: mobilde sidebar üstte ve tek sütun, masaüstünde yan yana ve iki sütun
- Hover efektleri (link ve kart geçişleri)
- Diğer projelerime yönlendiren linkler

## Öğrendiklerim
- Tailwind'in utility-first yaklaşımı ile saf CSS arasındaki fark
- Tailwind'de responsive prefix kullanımı (`md:flex-row`, `md:grid-cols-2` gibi)
- Tutarlı bir renk paleti kullanmanın (rastgele hex değerleri yerine Tailwind'in hazır tonlarını tercih etmenin) görsel uyuma etkisi
- Vite ile build alıp GitHub Pages'e deploy etme süreci (ve node_modules'ı .gitignore'a eklemeyi unutmamanın önemi)

## Kurulum (kendi bilgisayarında çalıştırmak istersen)
```bash
npm install
npm run dev
```
